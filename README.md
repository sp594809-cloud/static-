# Koshti & Company — Static Website

Fully static site. No Node.js / database / admin panel.

## Local preview
Open `index.html` in a browser, or run:
```
npx serve .
```

## Render Static Site settings
- **Root Directory:** leave empty (or folder that contains index.html)
- **Build Command:** (leave empty)
- **Publish Directory:** `.`  (or `public` if you keep that folder name)

Enquiry forms open WhatsApp with a pre-filled message.

Update WhatsApp number in `js/data.js` → `config.whatsapp` (e.g. `"9198XXXXXXXX"`).
